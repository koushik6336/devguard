About DevGuard

A 4-part project building a production-grade DevSecOps pipeline from scratch.

DevGuard demonstrates how to build a fully automated DevSecOps deployment pipeline — starting from a simple Flask web app and progressing to a production-ready system with CI/CD, security scanning, containerisation, and cloud deployment. Security is shifted left: checks run at every stage, not as an afterthought before production.

Project roadmap

1

Flask app + Docker + tests

Current stage. Flask routes, Dockerfile, pytest suite.

2

GitHub Actions CI/CD

Automated pipeline triggered on every push to main.

3

Security scanning

Bandit for Python code, Trivy for container images.

4

Cloud deployment

Deploy to AWS ECS or GCP Cloud Run.

Tech stack

Python 3.11 Flask 3.0 Docker pytest GitHub Actions Bandit Trivy AWS ECS GCP Cloud Run
